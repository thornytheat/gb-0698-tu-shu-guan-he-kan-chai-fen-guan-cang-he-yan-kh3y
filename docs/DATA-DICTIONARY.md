# 期刊记录定义

record_id、copy、volume作为字符串保留前导零。ISSN检查8位格式，不校验国际注册关系。title支持本仓内别名字典。year范围1900—2100。

issue支持1、1-3、3/4以及S1。连字符表示含两端的期号范围，斜线表示列举。常规期号1—24；增刊不计入常规年度12期。status取held、suspended、missing。held实际册由ISSN+年度+复本+binding唯一确定；合刊一册可覆盖多期。同复本同一期处于不同binding时报装订冲突。

缺期=1至12减去已持有期减去明确停刊期。缺期是补录任务，并非质控阻断；装订和刊名身份冲突阻断复核。馆藏输入行数与覆盖期次、实体册分别对账。

held记录必须有binding装订号，缺失进入BINDING_REQUIRED隔离，不得把空装订号的多册合并。

## 刊名年中更换与年度馆藏链

刊名在年中更换时，同一年前半年的旧刊与后半年的新刊共用同一卷号。处理约定：

- **当期原始刊名**：每条记录的title原样保留为`issue_title`，别名映射只产生`canonical`，不回写title。逐期凭据里`issues[].title`始终是该期实际到馆刊名。
- **年度馆藏链**：同年度、同卷号、期次覆盖严格前后相继（前段含第1期、后段从年中接续、两段不重叠）的刊名版本归并为一条链`chain_key = 年度|卷号|ISSN集合|最新规范刊名`。同ISSN下的不同刊名直接归链；跨ISSN还需刊名同族（相等或前缀包含）。
- **不误并**：期次覆盖相交、或后段又从第1期起算的，视为同卷号的独立刊物，各自成链。
- **冲突**：同复本同一期出现两个刊名报`TITLE_CONFLICT`，刊名在年度内重复出现且非相邻报`TITLE_SEQUENCE`；两者都阻断复核。
- **缺口按链核算**：缺期=1至12减去链内held期减去suspended期。只看最新刊名会漏掉旧刊覆盖的缺口，按两个刊名分别核算又会重复生成补录，因此补录任务按`ISSN·年度·期次`去重，`title`取该期实际刊名。
- **晚到记录**：某年度链复核归档后，该链的缺口被冻结为`confirmed_missing`。之后到达的旧刊记录（命中已确认缺口）只登记为`late`凭据，不改写确认缺口；本次新出现的缺期列入`new_missing`供复核。
- **中断续算**：核验按年度推进，每完成一年写入检查点。中断后从最后一个连续完成的年度恢复；中间年度缺失时，从该年度重新计算，其后年度一并重算。

字段说明（导出`evidence`列JSON）：

| 字段 | 含义 |
|---|---|
| `titles` | 年度链内的刊名版本列表，含title、issn、from_issue、to_issue、record_ids |
| `issues` | 逐期凭据，含issue、title（当期原刊名）、status、bindings、records |
| `missing` | 年度缺口：已确认时为确认缺口，否则为本次观测缺期 |
| `confirmed_missing` | 已确认的年度缺口快照 |
| `observed_missing` | 本次观测缺期（不覆盖确认缺口） |
| `new_missing` | 确认后新出现的缺期，待复核 |
| `late_issues` | 已确认缺口中本次到馆的期次，仅登记 |

不做采购下单：输出的最末业务动作是`待补录`复核清单。
